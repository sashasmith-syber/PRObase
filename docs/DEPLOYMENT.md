# Deployment Reference

This document provides a quick deployment reference for AIT PROfessor.

## Build

```bash
npm run build
```

The production build is output to `dist/`.

## Firebase Hosting (Reference Path)

1. Install Firebase CLI:
   ```bash
   npm install -g firebase-tools
   ```
2. Authenticate and initialize hosting:
   ```bash
   firebase login
   firebase init hosting
   ```
   - Set `dist` as the public directory.
   - Configure as a single-page app (rewrite to `index.html`).
3. Build and deploy:
   ```bash
   npm run build
   firebase deploy
   ```

## Alternative Hosts

Any static hosting provider (Netlify, Vercel, Cloudflare Pages) can serve the `dist/` folder generated by Vite.
